# ChordClicks changelog

The newest version is at the top. Each release's section becomes the GitHub release notes and the "What's new" dialog in the app.

## 3.4.0 — 2026-10-27
- **Practice plan**: the Plan button builds a short routine for the loaded song — tune up, learn the chords you haven't marked known, drill the hardest change, loop the busiest section at 70% with the tempo ramp, then play it through. (Pro)
- **Lesson paths** in Learn: "Your first 10 songs" (free), Barre chords, Fingerstyle foundations, Lead guitar, Theory you actually use. Ticks come from what you do in the app.
- **Chords from a recording**: pick an MP3/WAV in Find and get a timed chord sheet, on the device, no upload. (Pro)
- **Stage mode**: full-screen chord sheet in big type, pedal page turns (Page Down / →), next song at the end. (Pro)
- **Backing band**: four new styles (Pop, Country, Reggae, Half-time), keys under the ballad styles, fills before section changes, walking bass into the next chord, and **Export WAV** for any song. (export is Pro)
- **Weekly report** in Learn → Progress, with "Email it to me" through the helper server.
- **What's new** dialog after an update, and this changelog on the website.
- Pro trial is tied to your email on the helper server, so clearing the app doesn't restart it.
- Looper shows which capture path it is using (audio thread or fallback) so drift is explainable.
- Helper server: Square webhook issues keys automatically, trial endpoint, weekly-report mail, owner export for backups.

## 3.3.1 — 2026-10-26
- Helper server address comes from 506clicks.ca automatically; phones and the web app need no setup.
- Content-Security-Policy allows the helper server, so Ultimate Guitar search works in the web and phone builds.

## 3.3.0 — 2026-10-25
- ChordClicks Pro: scored solos, trainer, neck (arpeggios, triads, CAGED), looper, stream tools, unlimited library, fingerpicking patterns, sync. 7-day trial, keys verified offline.
- Ultimate Guitar on web and phone through a helper server.
- Library multi-select with bulk playlist/genre/delete.
- Welcome tour and a startup message for the free tier.

## 3.2.0 — 2026-10-24
- New look: paper, ink and red, condensed display type, hairlines instead of gradients.
- iPhone: camera and microphone opened in one capture, so recording really records.
- Tuner: decimated YIN with octave check and string hysteresis; lighter on phones.
- Record mode: countdown, trim, save to camera roll.
